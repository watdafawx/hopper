Drag to select (try it)

Press on any tick box and drag up or down: every row you pass over takes the same state as the first one. Start on an empty box to tick rows, start on a ticked box to untick them. Drag past the top or bottom edge and the list scrolls by itself.

Drag on the box columnTicks (or unticks) every row the pointer crosses. Going back over a row while still dragging restores it.
Shift + clickTicks everything between the last box you clicked and this one.
Auto-scrollHold the drag near the list's top or bottom edge and the list scrolls, picking up rows as they pass.
Clicks elsewhereName, icon (mod peek), toggle and delete work as now. A drag only starts on the box column.
