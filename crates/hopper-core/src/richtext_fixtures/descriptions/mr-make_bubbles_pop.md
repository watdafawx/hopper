## 🫧 Features

This client-side mod makes bubble particles pop and completely overhauls their behavior to let them rise realistically to the water surface.
It also adds bubble particles to opening chests, opening barrels and explosions underwater.

Fixes [MC-132067](https://mojira.dev/MC-132067).


## 🔧 Installation

Download the latest release and drop the `.jar` file into the `mods` folder in your Minecraft directory.

To configure Make Bubbles Pop, install [MidnightLib](https://modrinth.com/mod/midnightlib) for Fabric or [Configured](https://www.curseforge.com/minecraft/mc-mods/configured) for Forge alongside it.
