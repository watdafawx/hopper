# Following a friend's pack: changes arrive by themselves, even after a hiccup

**Branch:** t3/fix-follow-auto-apply   **Commit:** ff09536   **Size:** M
**Apps:** desktop only (Hopper Server has no Friends follow)

## From -> to
- Before: if applying a friend's change failed once (a file held open, internet blip, game holding the mods), it was never retried; the row showed an Update button and the error sat only in Tasks. Restarting didn't help.
- After: every followed pack with a newer version applies by itself: on start, when it arrives, after a failure (2, 2, 3, 5, 10, then every 15 s) and when the game closes. The row says what's happening in plain words. Update only appears for mods from GitHub/other links that need the player's OK.
