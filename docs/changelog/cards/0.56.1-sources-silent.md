# Sync says when a mod's source didn't go along to a panel

**Branch:** claude/sources-silent   **Commit:** 498af38 (first c7ddf84)   **Size:** M
**Apps:** both (core shared; desktop shows a line + button, panel shows a hint)

## From -> to
- Before: with the panel's "mods from links" off, synced GitHub/link mods showed "Unknown" on the panel, with no word why (carry only logged a warning).
- After: desktop sync result gets one line, e.g. "9 mods' sources didn't go along: this panel has mods from links turned off." plus a "Turn it on in the panel" button (opens Settings > Mod sources). The panel's Mods tab, Unknown view, shows a dismissable hint ("may not have come along ... Turn it on in Settings > Mod sources") while the setting is off.

## Notes for the maintainer
- Button only opens the page; turning the setting on from Hopper was left out (security setting on another host).
- Old panels with no `attached` field count as all attached (silent, as before). Local-folder servers without a hopper.json stay silent.
- Panel hint can't know instance sources, so it says "may".
- Slots in target/perf* are shared between sessions: copy the exe from the slot cargo-ccd1 prints.
