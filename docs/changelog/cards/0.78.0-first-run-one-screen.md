# First run: one "Here's what we found" screen instead of a 7-step wizard

**Branch:** t3/first-run-one-screen-setup   **Commit:** fefdd8b8 (merged with main: 47bbbbeb)   **Size:** M-L
**Apps:** both (desktop setup dialog; Hopper Server's panel-folder screen)

## From -> to
- Before: a 7-step wizard (step dots, Back/Next, a Done summary) asked about folders, launchers, look, servers, the CurseForge key and install one by one.
- After: one dialog, "Here's what we found": the launchers found (switched on, read in place, nothing copied), the Discord row, and one "Use these" button. Look, Servers, CurseForge key, Install and Hopper's files sit under "More" in the same dialog. With nothing found it says "Welcome to Hopper" and the main button is "Find a modpack" (opens Browse). Skip adds no launchers and leaves an empty Library with its "Find a modpack" button.
- Hopper Server: the panel-folder screen now shows "Here's what we found" with the servers the panel lists, one "Use these" (saves and restarts), the folder picker behind "Change…", and "Skip" for "Not now". Nothing found: "Welcome to Hopper Server" with the picker open.

## Settings that moved
| Setting | Old wizard | Now |
|---|---|---|
| Launchers to show | own step, list of tick boxes | main view, a switch per launcher; "Add a folder…" for others |
| New instances folder | own step | main view with 3 or fewer launchers found; under More with more |
| Discord | (added in 2a7098e4) | main view, unchanged wording and `discord.enabled` |
| Look | grid of theme cards | More: Follow Windows / Hopper Dark / Hopper Light + "More themes" menu (live preview) |
| Servers | own step | More: None / On this PC / On another PC (+ folder and host) |
| CurseForge key | own step with screenshots | More: "Your own key is saved" + "Paste a different key…"; the screenshots are in that fold |
| Install / Portable | own step | More: "Install Hopper" button + "Or keep it portable" line |
| Hopper's files location | own step | More: path + "Move…" |
All of these are also in Settings, as before.
