## How tested
- Tests: 22 pass. Failing on purpose: `gap_a_members_undo_then_another_change_reaches_the_sharer`, `gap_the_change_made_last_wins_whoever_comes_back_first`, `gap_a_publish_lost_in_a_mailbox_crash_is_sent_again`, `gap_a_pack_pushed_out_of_a_queue_is_not_lost_silently`, `gap_storage_full_says_what_to_do`.
- On screen: rig slot 3 build, two Hoppers (scratch data dirs, loopback, test window, MCP 47832/47833) talking to a scratch mailbox on FOX 127.0.0.1:18797 through `ssh -R` tunnels (one shared, one only for A, so A could go offline alone). Offline = A's tunnel killed / B's Hopper closed; mailbox down = relay process stopped.
- NOT checked on screen: three members at once, member removed / group deleted / unshare while offline, queue-full message, crash during an apply, loader change, Hopper Server.
- Test data: throwaway "Sync Test" instance (Fabric 1.21.1, 5 small mods). Deleted at the end with the scratch dirs.
