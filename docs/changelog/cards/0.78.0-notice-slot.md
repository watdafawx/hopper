# One notice slot above the tabs (instance and server pages)

**Branch:** t3/one-notice-slot   **Commits:** 8fa41886, merge d80e5438, dea14380 (rig-run fixes), merge 5ab36bbc (main)   **Size:** L
**Apps:** both (desktop instance + server pages, Hopper Server server page + overview)

## From -> to
- Before: warnings stacked as separate bars above the tabs (stuck start, CF app change, pre-join, group pack, crash) plus banners above the Mods table (load problem, missing deps, duplicates, shaders, restart, only-here, client-on); they showed only on some tabs and pushed the page down.
- After: one slot above the tabs on every tab. It shows the two notices that matter most (Stops play > Needs a choice > For your information, newest first) as one-line strips; the rest fold into "N more", a list grouped by tier. The load problem's filled button is "Roll back {mod} to {ver}" plus "See why". Dismissed notices stay gone until their cause changes; Stop notices can't be dismissed. Narrow (side panel open / under 34rem): subject drops, labels shorten, "N more" -> "+N", one line each.
- Now also: desktop shader notice on every tab (instances only: servers don't draw shaders). Web Mods notices (restart, mod in twice, client-only on) reach the slot on every server tab, not only Mods.

## Fixed from the screenshots
1. Desktop: the lead strip shrank when its details opened (`flex_shrink` default 1): now `.flex_none()`, 67 px open and closed.
2. Desktop: dark red title 3.69:1 on its own strip -> new `theme::ink_over` lifts it to 5.04:1 (#e45b5b on #221415).
3. Desktop: "N more" list buttons didn't line up (chevron column 31 px off on rows without details/✕): invisible placeholders, now 0 px.
4. Desktop: a duplicate "Put 2.6.1 back" button sat in the crash row under the strip's own "Roll back": removed; row keeps Turn off.
5. Desktop: under 46rem a long title and long button left the subject 3 letters: subject drops below 46rem (it's in the title tooltip).
6. Desktop: Crash Assistant banner title now truncates so buttons never slide under ✕.
7. Web: `.nstrip` had `overflow: hidden`, which clipped the "N more" list to nothing (in DOM, `elementFromPoint` hit the page). Removed; title/subject still truncate on their own.
8. Web: then at a 467 px viewport the list's left edge sat at -1 px (anchored to the button, `100vw - 32px` wide). Now it hangs from the strip: right edge = button's right edge, width capped at the strip's.
