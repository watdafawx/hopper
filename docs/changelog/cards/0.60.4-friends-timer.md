# Friends: invite countdown, scrolling, clear direction, Escape leaves Settings

**Branch:** invite-timer   **Size:** S
**Apps:** Hopper desktop only.

## From -> to
- The mailbox server already returns how long an invite lasts (`expires`); Hopper threw it away and printed "15 minutes". Now the deadline is stored and the caption counts down (`Expires in 14:57`), updates every second, and clears the code with "That code expired" when it hits zero.
- The Friends page did not scroll, so "On this network" was cut off. It now scrolls as a whole.
- Rows read "kimbley shared ATM10 with you", and a line under the friends says your packs are shared automatically and theirs are listed below. That answers "why does it say Get when I invited her".
- Escape left Settings on nothing, because the search box had focus and swallowed it. Esc now steps back to where you came from, falling back to the library.

## Files
- `crates/hopper-core/src/mailbox.rs`: `invite()` returns `(code, seconds)`, using the server's `expires` and a 15-minute fallback.
- `src/gpui/peers.rs`: invite deadline + one-second ticker, scroll container, wording.
- `src/gpui/settings_page.rs`: the search field no longer takes Escape.
- `src/gpui/app.rs`: Escape on Settings steps back.

## How tested
- Throwaway data dir, throwaway instance, a real mailbox account (`hopper-test` style) on the public mailbox; invite made, clipboard read, countdown watched.
- NOT checked: leaving the Friends page and returning (the countdown lives in the view; no shortcut to reopen the page in the scratch build), narrow widths below 1000 px.

## Notes
- The countdown is local: it starts when the code arrives and assumes the server's 15-minute life. If the server changes the TTL it is read from `expires`.
