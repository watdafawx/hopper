# Hopper Server: other panels in your server list

**Branch:** t3/multi-panel-web-ui   **Commits:** 591718e, 3e96bbe (merge main), b282417   **Size:** L
**Apps:** Hopper Server only (desktop already has groups(); this brings the web UI to the same idea)

## From -> to
- Before: the web UI showed only the servers of the panel you opened.
- After: "Add a Hopper Server" adds other panels; their servers show in the same list, grouped per panel with its health, your role there, and a menu. Their server pages (console, files, downloads) work against that panel. A panel that's down or signed out only affects its own group.

Mock: https://claude.ai/artifact/YKJ3z92GiT7AyHpKPRAAtv (Option A built).
