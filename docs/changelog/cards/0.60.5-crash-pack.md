# Crash help: names the resource pack you just turned on when the game crashes drawing blocks

**Branch:** t3/crash-detect-resource-pack-trigger   **Commit:** 10ab029   **Size:** M
**Apps:** both (the rule writes the card's existing advice line, which both apps show).

## From -> to
- Before: after turning on the "Matcha Block Overlays" resource pack, ATM10 crashed with "Encountered exception while building chunk meshes" and the card blamed FramedBlocks (Likely), with Fusion and Sodium as Possible, and offered to turn FramedBlocks off.
- After: when the game crashes while drawing blocks or models and a resource pack was turned on just before (in game within 2 minutes, or the same crash right after it was turned on last time), the card names that pack as Likely: "You turned on the resource pack "Matcha Block Overlays 2-b1+fusion" 40 seconds before this crash, and the game crashed while drawing blocks. Turn that pack off (Resource packs tab) and play again." The mods drop to Possible.
