# Defaults: Discord switch in setup, SFTP off until switched on, update check can be turned off, README sign-in fix

**Branch:** t3/5fb8ddfa   **Commit:** 2a7098e4   **Size:** S (four small parts)
**Apps:** both. Desktop: setup wizard + two captions. Hopper Server: SFTP default + switch, update-check setting. README covers the desktop sign-in text.

## From -> to
- Before: Discord presence was on with no word about it in the setup. Hopper Server listened for SFTP on 0.0.0.0:8022 on every new install. The panel always asked GitHub for new versions every 30 minutes. The README said playing without Mojang's launcher needs `MS_CLIENT_ID` in `.env`.
- After:
  - Setup, last-but-one step ("Make it yours"): switch "Show what I'm playing on Discord" (on unless the saved setting is off) with one line of what friends see. It saves when clicked; nothing else changes for existing users.
  - Hopper Server: a new install has SFTP off (`sftp_port = 0`). Settings > Access & devices has an SFTP card with a switch; it works at once (no restart), off also closes open SFTP connections. A config that already names a port keeps it; an old config that never named one keeps 8022 (it was on before).
  - Hopper Server: Settings > Updates has "Look for new versions" (on by default). Off: no checks every half hour (panel and the Windows tray), turning it on checks at once. "Check now" and the versions window still work when asked.
  - README: playing without Mojang's launcher works out of the box in releases; the `.env` note is for builds from source only. Captions in the sign-in dialog and in Settings only show when the build has no app id (they already checked `client_id().is_none()`); wording now says releases have one.

## Notes for the maintainer
- Existing installs: a `hopperd.toml` that already has `sftp_port` keeps it, including 0. One that never named the port (very old) keeps 8022, because SFTP was on for it before.
- Turning SFTP off forgets a custom port (on again = 8022). The PUT also takes an optional `port` for scripts; the web UI sends none.
- Docker: `-p 8022:8022` in the docs now needs the switch too. Not changed here.
- Desktop: one switch (`discord.enabled`); `show_browsing` stays as it is (the line names it). The first-run redo can move the switch.
- `docs/index.html` never said the `.env` thing, so it is unchanged.
- Found on the side: unused import `TUNNEL_VERSION` in `crates/hopperd/src/tunnel/mux.rs` (not mine), dead `knock_on` in crashdetect.rs.
