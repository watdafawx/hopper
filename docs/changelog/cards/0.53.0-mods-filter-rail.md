# Mods tab: filters collapse into an icon rail (desktop + Hopper Server)

**Branch:** claude/filter-bar-b-844cc2   **Commit:** b738fd7, cc99fc8 (desktop), 8ff9497 + web narrow fix (see git log)   **Size:** L
**Apps:** both (web UI = Hopper Server pages only, so Client-only always shows there)

## From -> to
- Before: text tabs (All / Updates / Disabled / ...), grey chips for Added by you and Config changed, separate Update all and refresh buttons, Sort button with a long label.
- After: one rounded icon rail. The picked filter (All by default) shows icon, name and count; the others are icons with a tooltip "Name · count". Added by you / Config changed are toggles after a thin separator: on = same tint plus a ring, combine with any pick. Update all + refresh are one split button. Sort is icon-only until the order isn't the default. Client-only shows on server pages only.
