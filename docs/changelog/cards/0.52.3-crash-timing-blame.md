## Notes for the maintainer
- The rule fires only for a loader-named mod whose own stack has a ConcurrentModificationException (or Guava `validateIterator`) thrown from another mod's frames. A race in a library whose stack the loader doesn't print is not covered.
- Both reports of the same race group into one entry ("x2") in the card now since they blame the same mod.
- Moonlight is not special-cased: any other mod above the named mod's frames gets the same treatment.
