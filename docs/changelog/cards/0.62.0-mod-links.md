# Mod links from Discord, browsers and other apps open in Hopper

**Branch:** t3/e67eeb85 (worktree t3-e67eeb85-60cc1a5cff600287)   **Commits:** f5e0263, 2e57f1a, 2427101 (not pushed)   **Size:** L
**Apps:** desktop only. Hopper Server has no equivalent: it runs in a browser on another machine, so it can't watch your clipboard or be your PC's link handler.

## From -> to
- Before: a CurseForge or Modrinth link copied in Discord or clicked in another app opened the website; only curseforge.com's Install button (curseforge://) reached Hopper.
- After: two opt-in switches in Settings › Mod sources › "Links from other apps":
  - **Offer to open copied mod links**: copying a project link anywhere shows a Windows notification "Open Sodium in Hopper? / You copied a Modrinth link." with Open / Dismiss. Open brings up Hopper's panel for that project.
  - **Open mod links in Hopper**: Hopper appears in Windows' Default apps as a browser. Once the player picks it there, clicked mod links open in Hopper (the running one, or it starts), and every other link goes straight on to the browser chosen under "Other links open in" (default: the one Windows used before). Off removes the entry.
- Links with a file or version (`/files/6600309`, `/version/mc1.21.1-0.6.13-fabric`) open the project with the "Opened from curseforge.com / modrinth.com" card for that file. That card used to say curseforge.com for Modrinth too; fixed.

Mock: `mock.html` here, published https://claude.ai/artifact/M58vvHk6pyYKBao3v5KRrq. Picked Settings A (both switches in Mod sources, Windows steps only when needed) and Toast 1 (Windows notification: Windows keeps it out of games and Do not disturb, shows while Hopper is minimised, never takes focus).
