# Hopper desktop: readable chip and status pill text on light themes

**Branch:** t3/desktop-chip-text-contrast   **Commit:** 85afa8a   **Size:** M
**Apps:** desktop only (Hopper Server's web UI got the same rule in 613dc21)

## From -> to
- Before: `widgets::chip` darkened its text just enough for ~5:1 (`theme::ink`); `widgets::pill` (Custom, Your key, Not checked, No panel, Connected, Running...) and several hand-built chips (the version chip, needs / breaks) used the plain colour: 3.1-4.4:1 on light themes.
- After: one rule, `theme::chip_ink`: light themes mix the colour half way to black in sRGB (the web UI's `color-mix(in srgb, c 50%, #000)`); dark themes keep the plain colour. Every chip, pill and hand-built chip uses it, so desktop and web chips match.
