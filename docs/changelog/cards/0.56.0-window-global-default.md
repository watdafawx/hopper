# Window setting: set a default for all instances in Settings

**Branch:** window-global-default   **Commit:** 31fe0ea   **Size:** M
**Apps:** desktop only. Hopper Server's web UI has no game-window setting (servers have no game window; grep of `crates/hopperd/ui` finds none).

## From -> to
- Before: Window / Maximized / Fullscreen and the size existed only per instance (Settings tab of each instance).
- After: Settings > Playing & Java has the same control as a default. An instance follows it ("Using the default from Settings.") until it has its own value ("This instance's own setting." + **Use default**). Instance wins. With no default set, nothing changes.

## Notes for the maintainer
- Old instance files have no flag: they count as "own" when they differ from 1280x720 Window, else follow the default. New field `window_own` (omitted from JSON when unset).
- A global default equal to the stock window is not saved (it behaves the same as unset).
- Typing in the global size fields saves as you type (like the Java defaults); numbers are clamped 640-7680 x 480-4320.
