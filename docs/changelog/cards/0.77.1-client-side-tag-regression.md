# Server sync: client-only pack mods stay off after a replaced server pack

Branch `t3/e4ec1277`, commit `d9b6114` (not pushed, no version bump).

## What the user saw (0.77.0)
- TNP Limitless 8 - LL8, Mods tab: Inventory Profiles Next 2.2.5 has no side chip and a "?" icon; the peek says "Client".
- IPN now shows on the server sync page as a mod to put on the server.

## Cause
- Not a Hopper commit. The pack author replaced the 1.80.0 server pack on CurseForge (2026-11-15): the file Hopper recorded at update, 9612710, is deleted; the current one is 9612933 (`LL8-Server-Files-v1.80.0.zip`).
- Hopper reads the server pack only by the recorded id. The read failed ("server pack list ... 1 failed" in `sync-timing.log` since then), so the sync fell back to CurseForge's Client tags.
- IPN's CurseForge file has no Client/Server tag (`gameVersions: ["1.21.1","NeoForge"]`), so `env` is "" (already "" in backups back to 2026-10-19). Only Modrinth calls it client-only. Before, the server pack left it out, so it never showed.

## Fix (hopper-core)
- `serverpack::current`: if the recorded server pack can't be read, ask the pack file for its current server pack and use that. Also cached under the old id, so later compares don't ask again.
- Without a readable server pack, pack mods with no CurseForge side tag are also asked on Modrinth (mods the user added already were). Client-only there means won't sync, "Client-only on Modrinth". A CurseForge tag still wins, and so does "Sync anyway".
- `hosting::find_server_pack` / `resolve_server_pack` (making a server from the pack) follow a replaced server pack the same way.
- Heal: no re-import. The next sync compare finds 9612933 and caches it.

## Checks
- New tests: `untagged_pack_mods_go_by_modrinth_without_a_server_pack` (fails on the old filter: `left: None`, `right: Some("Client-only on Modrinth")`) and `a_replaced_server_pack_is_followed`.
- `cargo test -p hopper-core --lib`: 1461 passed, 0 failed, 62 ignored.
- Not checked on screen: needs a paired scratch Hopper Server and a CurseForge pack whose server pack was replaced. No screenshots.

## Not changed
- The Mods tab "?" for IPN and Illager Invasion: both CurseForge files carry no side tag, so "?" is what CurseForge says. Showing Modrinth's side there is a separate change, so it isn't part of this one.
- Hopper Server has no client-to-server sync of its own; nothing to change there.
