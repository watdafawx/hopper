# Friend groups: a mod removed while a friend plays stays removed

**Branch:** t3/groupsync-removed-mod-readded   **Commit:** 79361df5   **Size:** S
**Apps:** desktop (+ shared core, so Hopper Server's mod lists get the same rule). Hopper Server takes no part in friend groups.

## From -> to
- Before: you removed a mod from a group pack while a friend was in game; if their game held the jar, it waited in their mods folder, and any older copy of their mod list read back meanwhile (CurseForge's own file, or a stale save as the game closed) listed it again, so their next update sent it back to everyone as their own, newest change.
- After: a jar waiting for the game to let go counts as gone, so nothing can list it again; and the play time saved when a game ends no longer writes the whole (possibly older) in-memory instance over the file.
