# Friends panel: one row per friend, their packs on their own page

**Branch:** t3/0b6162cf   **Commit:** 7597a9c   **Size:** L (briefed as M; it grew: every existing state had to move onto the new pages)
**Apps:** desktop only. Hopper Server has no Friends panel.

## From -> to
- Before: one long list with every friend and every pack they share stacked under them; Invite and Join sat in a fixed bar at the bottom.
- After: one row per friend (face, online dot, name, pack count, "2 new"). Clicking a row opens their packs inside the panel with "‹ All friends" (Escape also goes back). Packs you follow sit on top, the ones with an update first. Follow shows on row hover and on keyboard focus. Invite, Join with a code and New group live in the header's + menu; the bottom bar is gone. Groups get their own page with every old state.

## How tested
- Tests: `cargo-test-changed.ps1` (6 binaries, all pass); `friends::` tests, `players_never_see_the_services_own_words`, `settings::` tests pass.
- On screen: scratch builds (hv-fm.exe, MCP 47833, `HOPPER_LOOPBACK=1`, scratch `HOPPER_DATA_DIR`) against a local scratch relay seeded with 8 friends (one with 15 packs and a 60-character pack name), a followed pack with an update waiting, a pack with missing files, a group, a group invitation and an ended follow. `state` showed only the 3 scratch instances every run. Clicked rows, back, Escape, the + menu, Invite (made a code), the reminder, search, the group page; Tab to Follow.
- NOT checked:
  - Update was never clicked (it would install the pack); Join / Decline on the invitation, the group's "keep in step" switch and the friend ⋯ menu items were not clicked.
  - No news dot on the Friends tab itself (only per-friend chips).
  - Search doesn't highlight the matching words.
  - The invite ✕ only hides the reminder; the code still works until it runs out.
  - Light-theme chip contrast elsewhere in the app (only these two chips are darkened here).
  - Other zoom levels; screen readers.
  - Hopper Server: no Friends panel, nothing to match.
- Test data: everything under the session scratchpad (`fm/`), deleted after. A temporary edit to the scratch settings (Following chip shot) was reverted.

## Notes for the maintainer
- Plain (not signed in) faces in the Friends panel are now the same rounded square as Minecraft heads, with an edge line so they show on light themes. Heads themselves are drawn square by `accounts::head` (its rounded frame doesn't clip the image); not touched.
- Text columns differ by section (pack icon vs face vs face stack). A fixed leading slot would line them up; not done.
- The caption colour on a hovered row is 4.15:1 in Hopper Light. That's the shared `widgets::caption` on `widgets::row_hover`, app-wide.
- The Mods table clipping beside the dock is untouched (separate task).
