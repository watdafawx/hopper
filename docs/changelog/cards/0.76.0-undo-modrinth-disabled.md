# Undo brings back a Modrinth pack mod's own file; updating a turned-off mod keeps it off

**Branch:** t3/621a778b   **Commit:** 5a5519a   **Size:** M
**Apps:** both. Everything is in hopper-core. Desktop and Hopper Server use the same update path (`install::replace_addon`) and the same group sync code.

## From -> to
- Before (Modrinth pack, group): a member undid their update or removal of a pack mod. Other members only got the note "putting back the modpack's own file isn't done by sync" and kept the update. If their copy wasn't counted as the pack's, the mod was removed outright.
- After: the pack's exact old file comes back from the pack's own download link. It is hash-checked against the pack's index, turned on and counted as the pack's again. The update goes to History.
- Before (History Undo, Modrinth file): Undo always downloaded the version's main file. If the pack used another file of that version, the hash didn't match and Undo failed.
- After: Undo downloads the version's file that has the note's hash.
- Before (update of a turned-off mod): the new file took on/off from the mod's entry. Two cases brought it in turned on:
  - The player turned the mod off while the game held the jar. The switch waits for the game to close, and the Mods tab already shows it off.
  - The jar was `.jar.disabled` on disk but the entry still said on.
- After: the new file follows what the player sees: a waiting switch first, then the file on disk. The waiting switch for the old jar is dropped.

## Root causes
1. `groupsync::pack_file` returned None for every Modrinth pack: it only knew CurseForge manifests. Modrinth codes name pack mods `n:<file name>`, and there was no way to fetch "the pack's file".
2. `install::replace_addon` and `take_old` read `Addon.enabled` only. A queued switch (`locked::switches`) and the `.disabled` file on disk were ignored. The mekanism_magic note from 11 Nov (TNP LL8, read only) shows the old entry as `enabled: false` with its jar `.disabled`. I couldn't reproduce that exact run, so I can't say which of the two cases it hit there. Both are fixed and tested.
