# History: every row's text lines up, whoever made the change

**Branch:** t3/history-fixed-face-column   **Commit:** bde608c   **Size:** M
**Apps:** both (desktop History dialog, Hopper Server Mods > History)

## From -> to
- Before: each extra face pushed the row's text further right (desktop 804 / 848 / 891 px for 1 / 2 / 3 people), so rows and their nested files didn't line up.
- After: faces sit in one fixed column two faces wide. 1 person: one face; 2: both; 3 or more: the first face and "+n" (hover names the rest). Text and nested rows start at the same x on every row.

Mock (Design Artifact, 4 artboards: Now, A, B, C): https://claude.ai/artifact/9MDqp6UVMHtgLM1LbDqQii
Pick: **A, two-slot column + "+n"**. Fixed alignment, full-size faces never overlap or clip, "+n" stays whole, same rule on desktop and web. B (overlapped stack) hides faces and needs a ring that follows hover/selected tints; C (faces at row end) separates who from the sentence and fights Undo for room when narrow.
