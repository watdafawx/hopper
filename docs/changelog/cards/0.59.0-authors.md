# Mods: the Author column follows the installed jar

**Apps:** both (Hopper desktop and the Hopper Server web UI)

## From -> to
- Before: a mod tracked from GitHub kept the author saved in `hopper.json` when it was installed. After the mod's jar renamed its authors and the file was updated, the Mods list still showed the old name (`mtop`).
- After: the list takes the authors the installed jar names (`watdafawx`), and refreshes whenever a new jar changes them.

- The regression test `source_mod_authors_follow_the_jar` and the full release test suite passed.
- Seen on screen in Hopper desktop (0.58.0 before, the release build after) and in the Hopper Server web UI, on a throwaway instance/server with the four installed jars and a `hopper.json` still holding `mtop`/`mikey`.
- NOT checked: a real instance update through the update flow; a jar with no authors; other themes and widths.
