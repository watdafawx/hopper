# Friends: "On this network" replaces the Friends nearby tab

**Branch:** t3/fold-nearby-into-friends   **Commit:** see `git log` on the branch   **Size:** M
**Apps:** desktop only. Hopper Server has no "nearby PCs" screen, so nothing to port.

## From -> to
- Before: PCs on the home network (LAN / Tailscale) had their own "Friends nearby" tab on every instance, apart from the Friends panel.
- After: Friends has an "On this network" tile and page (own words, apart from the internet mailbox). Pairing, push/pull, Follow and file compare work from there. Instance menu "Share on this network" opens Friends at that page. The old tab is gone.

- On screen: two scratch apps on rig (loopback, dead mailbox URL so the relay is never touched). Added by address, accepted the code on the other PC, "See their packs", Files compare (2 differ), Get from their PC (2 files, then 0 differ), Follow, instance menu entry.
