# Pack update: resource packs and shaders you added get their own icons

**Branch:** t3/pack-update-rp-shader-icons   **Commit:** d9b3ce9   **Size:** S
**Apps:** desktop. Hopper Server's web UI: no change. Its pack update only covers servers (no resource packs or shaders), and it has no such list.

## From -> to
- Before: in "What stays > Your mods and packs", resource packs and shaders showed the mod cube, like hand-added jars.
- After: resource packs show the paintbrush, shaders the sun (data packs the database icon), the same icons as the instance page's Packs/Shaders/Data packs tabs (`InstTab::icon`, library.rs). Jars still show the cube. A real project icon still wins where one exists (the rows only fall back to the kind icon when no image is found).
