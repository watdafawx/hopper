# Give people and tokens "all servers on a node", and act on many servers across nodes at once

**Branch:** t3/a7889eb9   **Commit:** 655bee4   **Size:** M (ran well over: ~7 h)
**Apps:** Hopper Server (web UI + API + CLI + MCP). Desktop: no code change, checked with a scoped token; it has no multi-select on Servers (so no bulk there).

## From -> to
- Before: a person's or token's server list could only name single servers; bulk actions only covered this panel and other panels; the audit log had no way to see one node; a node's ceiling could only be changed by leaving and joining.
- After: "All on <node>" in the Users and API token pickers (covers servers made there later); bulk start/stop/restart/command covers node servers with skipped rows explained; "Select all on <node>" in the node's menu; Security › Audit log tabs per node with a node chip; `PUT /nodes/{id}/ceiling` and `hopperd node ceiling` (lower only); MCP tools work on node servers. A failed node update now survives a restart of the main; `--home` picks up a left-behind `node.json`.
