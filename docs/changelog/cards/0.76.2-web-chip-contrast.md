# Hopper Server: readable chip text on light themes

**Branch:** t3/web-ui-chip-contrast   **Commit:** 613dc21   **Size:** M
**Apps:** Hopper Server web UI only (desktop chips not touched; see Notes)

## From -> to
- Before: coloured chips, tags and pills (Running, Crashed, LAN, Client only, Server only, CurseForge, Modrinth, "manual", version chips...) used the plain theme colour on a ~10% tint of itself. On light themes that read at 1.4-3.5:1.
- After: one shared set of text colours in `app.css` (`--ink-*` variables and `.ink` with `--k`: History's fix made shared). Light themes pull the colour 50% toward black; dark themes keep the plain colour, so dark looks the same.

## Measurements
Method: headless Chromium screenshot per page and theme. Every chip-like element (own text, tinted background, 12-30 px tall) is found in the page. Its background = the commonest pixel on its top and bottom edge rows. Its text colour = the pixel furthest in luminance from that background inside the chip. WCAG ratio from those two sampled pixels (a slight under-estimate for thin 11 px text). 9 themes x 17 pages = 1035 samples before and the same 1035 after, matched one to one. Pages: Overview, Browse, Access, Settings, Security, Java; one scratch server's Mods, Mods > History, Backups, Settings, Logs, Configs, Data packs, Files, Schedule, Players, Worlds; plus a crashed scratch server (Overview, its page, its Logs).

- 13 components (Backups, Browse, DataPacks, JavaPage, ModBackups, Mods, ReviewUpdates, ServerAlerts, ServerCrash, VersionChip, VersionPage, lib/Comments, lib/FeaturedTag): chip text colour only; per-component copies removed (ModBackups' and Comments' own mixes now use the shared one)

## How tested
- Tests: `pnpm --dir crates/hopperd/ui check` 55 pass (loop lint + node tests). `cargo-ccd1 test -p hopperd`: 369 passed, 0 failed, 3 ignored on the rerun. The first run had one failure, `moves_tests::a_moved_or_sending_copy_refuses_every_start` ("is being restored from a backup"), a race: it passed alone and in the full rerun. Not touched by this change.
- On screen: scratch hopperd (`--portable --port 8799 --home / --data / --servers-root` all in scratch, `HOPPERD_SERVICE=hopperd-test`, `HOPPER_LOOPBACK=1`), headless Chromium via Playwright only. Built the baseline exe first, then the changed one, both run on the same scratch data.
- NOT checked on screen: the "computed" chips above; a running (green) server pill and the Starting pill (the scratch server could only be made to crash); update / breaking chips and History pack-update counts; Settings > Appearance live theme switching (themes were set through the saved choice and a page load); the Follow-system light/dark flip; zoom levels; other browsers (uses `light-dark()` and `color-mix()`: Chrome 123+, Firefox 120+, Safari 17.5+).
- Test data: 3 fake Fabric servers (jars with a `fabric.mod.json`), one backup, mod toggles (re-enabled), one scratch server made to crash with a run.bat that exits 1. The real `%APPDATA%\hopperd` was not touched (last written Oct 28). Scratch lives in the session scratchpad; servers stopped.

## Notes for the maintainer
- Dark themes: plain colour kept on purpose ("look the same"). Side effect: History's counts, which were already mixed toward the text colour on dark too, are now the plain colour on dark (still >= 4.5:1 in the colours used).
- Not chips, left alone: coloured plain text on the page background (History verbs `.ch.*`, BulkAction `.st`, Issues `.st`), icons in tinted squares/circles (`PackUpdate .si`, `VpsRelaySetup .st`, `AddPanel .ck`, `Worlds .wq`), banners and strips (`.warn`, `.path`, `.share`, Editor `.notice`, CrashStrip / StuckStrip), selected segmented / sort buttons (accent text on accent tint: `.seg button.on`, `.sorts button.on`). Same raw-colour-on-tint problem on light themes; follow-up if wanted (`--ink-*` is ready for them).
- Issues label chips (`.ilabel`) already mix their GitHub colour with the text colour; left as is.
- Desktop: not touched. Its chips (`widgets::chip` and pills) probably have the same low contrast on light themes; not measured.
- `Browse .chip.modrinth` uses its brand green through `--k` with the same 50% mix.
