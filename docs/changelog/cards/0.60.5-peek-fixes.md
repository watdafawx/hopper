# Browse: opening some packs no longer closes Hopper, and descriptions show their pictures instead of raw code

**Branch:** t3/fix-mod-peek-resource-pack-crash   **Commits:** a8b28e4, 62f381e   **Size:** S
**Apps:** both (the version sort and description renderer are shared; Hopper Server's update check had the same sort bug).

## From -> to
- Before: opening "Matcha Block Overlays" (Modrinth resource pack) from Browse closed Hopper instantly. Its version list mixes releases (26.3, 1.21.10) with snapshots (22w42a, 24w14potato), and the version sort could go in a circle, which Rust's sort treats as a fatal error.
- After: versions always sort in one order (newest first: 26.3 26.2 26.1.2 ...), the peek opens. Hopper Server's own update check got the same fix (1.0 vs 1.0.0).
- Before: Fresh Animations' description began with a grey code box full of raw `<img>`, `<center>` and `<details>` markup, because a one-line ```text``` was read as the start of a code block.
- After: the line shows as small inline code, then the Early Access images, a rule, the banner image and the text; the author's real code block shows as a code box.
