# Hopper Server: a node's servers in the main's list (nodes, part A2)

**Branch:** t3/hopperd-multi-panel-a2   **Commits:** d1518ae (WIP), b337ce5 (merge main), see `git log` for the final one   **Size:** L
**Apps:** Hopper Server only (desktop talks to panels, not nodes; nothing to match there yet)

## From -> to
- Before: a node joined a main and stayed connected, but served nothing; Settings › Nodes was hidden on main (`NODES_SHOWN = false`).
- After: a node's servers sit in the main's server list under their own group and open the same server pages (console, files, mods, configs, power...). The main can make servers on a node, pause a node (maintenance), and alerts when a node goes offline. Settings › Nodes is shown again.

No mock: the node group reuses B2's group header and health line (already agreed); the maintenance line reuses the health line and "Make it on" reuses the segmented control.

## Notes for the maintainer

- "Share on mclo.gs" shows on node servers but 403s (`logs/share` not relayed). Hide or relay: pick one.
- The "making" row for a new server on a node shows under the home group until done.
- The scratch Minecraft server bound its own ports on all addresses (server.properties default); hopperd itself stayed on 127.0.0.1.
