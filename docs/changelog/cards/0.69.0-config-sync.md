# Friend groups: share a mod's settings with the group

**Branch:** t3/selective-config-sync   **Commits:** 67fa3fd (relay), 3ea1797 (feature), dbdd710 (fixes)   **Size:** L
**Apps:** desktop + relay. Hopper Server phase not in this task (per master).

## From -> to
- Before: a group copy got the pack's mods, never anyone's settings; everyone tuned configs by hand.
- After: any member flips "Share these settings with <group>" on a mod in Configs. The settings they changed from the pack go first, then every later change, per key, to everyone in the group (offline friends catch up from the recipe). Passwords/tokens and never-share files stay home. Nothing is written while the game runs. Each arrival is a History row with Undo; "Keep mine" stops taking a mod's settings.
