# Mods tab opens faster and scrolls with less work on big packs

**Branch:** t3/gpui-desktop-perf-pass   **Commits:** c22798d, 5bb0af4, f92b0fe, 2cf5eab   **Size:** L (measure + contained fixes)
**Apps:** desktop only (both fixes are in the desktop Mods table; Hopper Server's web table already counted from the list it was sent)

## From -> to
- Before: opening a big pack's Mods tab read every untracked jar on the UI thread (~1 ms a jar), and every frame of the tab listed the mods folder twice to count untracked jars.
- After: untracked jars are read in the background (icons fill in when done); the count comes from the list sync already keeps. Nothing on screen changes.
- Also: settings.json is saved on a background thread instead of on the UI thread at every tab switch or sort click; the newest copy is flushed on quit, window close, restart, data move and panic.

## Other findings (measured, not fixed: bigger or riskier)
1. Library sidebar is not virtualized: with 68 instances, scrolling it costs p50 8-11 ms, p95 11-13 ms a frame (all rows laid out each frame; ~45% of it in layout). Matters only for people with many instances; needs a virtual list that handles group headers.
2. Every Mods-tab scroll frame re-renders the whole Library detail (GPUI marks every ancestor view dirty on scroll), ~2 ms of hopper render plus layout of the header. Architectural.
3. (Fixed in 2cf5eab, see table.) Tab switches and sort clicks saved settings.json on the UI thread.
4. Dialogs (What's new, History, Friends) first frame 20-25 ms: one dropped 60 Hz frame on open; opening also re-renders the sidebar and detail.
5. Image requests for the first 60 rows on tab open: 6-12 ms cold.
- Fine already: idle (0 frames over 5 s on any page), Logs with 80k lines (scroll p50 ~4 ms), Settings/Servers (~1 ms frames), tab switch navigate 2-6 ms warm.

## Notes for the maintainer
- Settings::save (direct) still writes at once; only the desktop store's saves go through the writer. Hopper Server is unchanged. Settings::load / load_or_default flush first, so a reader never sees an older file.
- Spans cost one check of the log file when HOPPER_FRAME_LOG is unset. Run with `HOPPER_FRAME_LOG=<file>` to get per-frame ms plus `name=ms/count` spans.
- Untracked-jar icons now appear a moment after the tab opens on a cold cache instead of the whole tab waiting for them. In the screenshots taken 4 s after opening, before and after are identical.
