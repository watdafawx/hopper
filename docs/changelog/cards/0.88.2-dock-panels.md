# Dock panels: Friends and mod config now close like the mod's page

**Branch:** t3/unify-dock-panel-dismissal   **Commit:** a67a20e1   **Size:** M
**Apps:** desktop only. Hopper Server's web UI has no right-hand dock with these three panels, so there is nothing to match.

## From -> to
- Before: a mod's page closed when you clicked elsewhere; Friends and the config file panel did not. Opening one panel left another open underneath, and it popped back when the top one closed. The config panel was narrower than the other two and kept its own width.
- After: one panel at a time. A click beside any of the three closes it (right click too). Opening another swaps. A config with unsaved changes is never dropped: an outside click, the X, opening a mod's page or opening Friends all keep it open and say "Not saved yet: Save, or Discard." All three share one width: drag any edge and the other two open at that width.

## How tested
- Tests: hopper 146 passed. No new unit tests: the logic is click and ownership state, checked on screen.
- On screen (test build on rig, scratch data, one throwaway instance): dark and light, full size and 960 wide. Config open, outside click closes, config then mod page, mod page outside click, Friends open and outside click, Friends then config, unsaved edits (outside click, X, open mod page, open Friends), right click, and dragging the edge of each panel.
- Measured on the screenshots (1 pt = 1.75 px): after one drag the three panels have the same width (borders at the same x, 0 px apart) whichever panel was dragged. The config panel's default width grew from 787 px to 840 px, the same as the other two.
- NOT checked: a dialog opened from inside a panel and then clicked (covered only by the code guard), Friends popovers (needs a signed-in account), dark themes other than Hopper Dark, dragging at the narrowest window.

## Notes for the maintainer
- Side findings, not fixed: the Ctrl+K palette is a custom overlay, so a click inside it closes the open panel (the mod's page too); the "Not saved yet" notice sits over the config panel's X for about 6 s; switching instance drops unsaved config edits silently; if the config panel is hidden behind another tab with unsaved edits, opening another panel is refused and switches to the Mods tab.
