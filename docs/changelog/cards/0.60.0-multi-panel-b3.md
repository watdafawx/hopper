# Hopper Server: pick servers across panels and start, stop, restart or command them together

**Branch:** t3/multi-panel-bulk-actions-filters   **Commit:** ce23d35   **Size:** M
**Apps:** Hopper Server only (desktop's server list has no selection or bulk actions yet; parity left for later)

## From -> to
- Before: each server had to be started, stopped or restarted on its own page; the list had no filters.
- After: a Select button in the list header turns on tick boxes; pick servers in every panel's group (click, drag across, Ctrl+A), then Start / Stop / Restart / Command from the selection bar. One question grouped by panel says what each server gets or why it's skipped, then the same dialog shows each result. Filters by panel and by state (All, Running, Stopped, Crashed).
