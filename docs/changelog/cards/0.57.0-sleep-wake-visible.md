# Sleep settings: wake-on-join is always visible

**Branch:** claude/sleep-wake-visible   **Commit:** see `git log claude/sleep-wake-visible`   **Size:** S
**Apps:** both (Hopper Server web UI + Hopper desktop's Sleep card for a paired panel)

## From -> to
- Before: with "Sleep when empty" off the card showed only that switch and "Off: it runs until someone stops it.", so nobody knew wake-on-join existed.
- After: the wake options (wake switch, who, while it starts, after a failed start, server list message, preview) always show. With sleep off they are greyed and disabled, with one line: "Turn on sleep above to use these: a server that sleeps wakes when someone joins." The line sits where the "Joining from Minecraft's server list..." line is when sleep is on, so nothing moves when sleep is ticked.

## Notes for the maintainer
- Save logic unchanged: the body always sends the wake values, the server keeps them when sleep is 0 (checked in `router.rs` PUT), and `dirty` compares the same fields, so no new test was needed.
- Preview of the server list message stays visible but dimmed (opacity .6) with sleep off: it shows what players would see once sleep is on, and the line above says sleep is off.
- With the stored wake switch off, the disabled state shows the wake switch unticked plus the explanation, like the enabled state's one-line note.
- The Schedule page's "Sleep" line and Network's sleep pointer still only show with sleep on.
