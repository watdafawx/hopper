# Friends groups: your copy is checked against the mods folder, and one click repairs it

**Branch:** t3/group-sync-verify-and-repair   **Commit:** f63f9e83 (released in 0.89.0)   **Size:** L
**Apps:** desktop only (Hopper Server has no friends groups: nothing in `crates/hopperd` touches `groupsync`, `group_copies` or the mailbox)

Pick: **A**. It reuses the existing group strip + its Details panel, so narrow windows and side panels already work, and the list is open the first time. B = strip only, list behind Details. C = a card inside the page.

## From -> to
- Before: "Same as the group" came from local bookkeeping (nothing queued, nothing failed), never from the mods folder, so a copy that silently lacked a mod said it was in step and nothing could repair it. Pull now only re-ran the merge.
- After: the strip says what the mods folder really holds. "Your copy matches the group." or "Your copy is missing 2 mods the group has." with one row per mod and a button per row (Get it / Update / Turn it on / Allow and get it), or "Hopper couldn't check CurseForge just now, so your copy might be missing something. Try again." One **Make my copy match** applies exactly the listed rows. Pull now now reads the group and then verifies and repairs. Nothing downloads before a press.

## Notes for the maintainer
- Not fixed, seen on screen: row pitch differs by 1-2 px between rows with a button and text-only rows; the strip title is cut with an ellipsis at the narrowest window and beside the side panel (full text in the tooltip, existing strip behaviour); the list column is 12 px right of the header icon column (shared Details padding).
- Limits of the check: a first-install left-out mod stays unseen until the sharer's next code; a pack's own mod missing is not detected; a mod the group removed that this copy still has is not reported; a removal made before the first publish shows as missing; Pull now repairs only when the group answered.
- Beyond the brief: "On here, off in the group" / "Off here, on in the group" rows (switch differences). Member name for `Member::Unknown` is "Not heard from yet" (the brief's example wording was different).
- Preview "repair" only clears the rows; the real repair was proven with the Modrinth scratch copy above.
- Rig: slot 1 build dirs `G:\rig-build\hopper` / `G:\rig-test\hopper` were created by this run (cold build 11 min) and left for push-to-rig's own eviction.
- Desktop only. Hopper Server has no friends groups, so there is no matching change there.
