# Friends: changes show up right away, with ~10x fewer calls to the relay

**Branch:** t3/friends-relay-push-events   **Commit:** ab3d37c8 (merged with main)   **Size:** M
**Apps:** desktop + relay. Hopper Server has no Friends panel, so there is nothing to match there.

## From -> to
- Before: the desktop read the friend list from the relay every 3 s (about 1,200 calls an hour per player, even when nothing changed). The panel only said anything about the connection when it was down.
- After: the relay says in the long-poll it already runs when a player's friend list changes, and the desktop reads the list only then. There is also a 5-minute safety read, a read when the window comes back after a minute or more, and a retry 20 s after a failed read. A quiet line under every Friends page says Connected / Connecting / Reconnecting / Offline.

## Calls per hour (one idle desktop, scratch relays on rig, 10 min each, from the relay's request log)
| Setup | GET /v1/friends | GET /v1/groups | GET /v1/recipes (feed) | Total |
|---|---|---|---|---|
| Before: main build | **1,194** | 60 | 60 | 1,314 |
| After: new build + new relay | **12** (the 5-min safety read) | 60 | 60 | 132 |
| After: new build + old relay (fallback) | **120** (30 s timer) | 60 | 60 | 240 |

Friend-list reads drop 99% (1,194 to 12 an hour). All calls drop 90%. Each real change (join, remove, rename, online or offline) adds one read.

## How fast changes show up (new relay unless noted)
| Change by the friend | Friend list read after |
|---|---|
| Rename | 0.46 s |
| Removes you | 0.61 s |
| Joins (from an invite) | at once (seen on screen; not timed) |
| Comes online after being away | ~2 s (seen on screen) |
| Goes quiet (offline) | 90.3 s after their last call (the relay counts 90 s as online, so this is the earliest it can be) |
| A call while already online | no read (correct: nothing changed; checked for 25 s) |
| Rename, against an **old** relay | 11.1 s (30 s timer) |
