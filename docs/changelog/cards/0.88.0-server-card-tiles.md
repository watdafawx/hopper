# Server tab card: state pill, vitals tiles, labelled Stop and Restart

**Branch:** t3/server-card-stat-tiles   **Commit:** 037fa44f   **Size:** M
**Apps:** desktop. Hopper Server's web UI already has this look on its server page (state chip in the header, labelled Start / Stop / Restart, a More menu), so `crates/hopperd/ui/src/ServerPage.svelte` is unchanged. Mock picked: option A "Stat tiles + labelled buttons" (https://claude.ai/artifact/5vNFKt8ukzoTcBvrmCzSNe).

## From -> to
- Before: header was `name · running` in tiny coloured text, then a thin row of signal bars, ping, players and a TPS badge; Stop and Restart were bare icons; a refresh icon ("Compare again") sat in the card header.
- After: header is dot + name + a state pill (Running / Stopped / Starting / Stopping / Restarting / Crashed / Sleeping / Couldn't wake / Unreachable). While running, three tiles: Players, TPS (green / yellow / red), Ping. Stopped says "Start it to see players, TPS and ping." Buttons read `Stop`, `Restart`, `Start`; Console and the ... menu stay icons on the right. "Compare again" moved to the comparison toolbar next to "Sync all..." as a refresh icon.
