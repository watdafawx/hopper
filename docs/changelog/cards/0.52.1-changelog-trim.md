# Versions and changelogs: only the notes for each version

**Branch:** (merged before this changelog existed)   **Size:** M
**Apps:** both (desktop dialog + Hopper Server web UI), one shared trimming function in `hopper-core`

## From -> to
- Before: a mod file's changelog that repeats every older release was shown in full. Oh The Trees You'll Grow 5.3.6 listed 5.3.6 down to 5.3.0 and beyond.
- After: each card is cut after its own version's section, the rest sits behind a collapsed "Earlier versions" row. A newer card is also cut at the installed version. If the headings can't be read, the full text is shown, never less.
