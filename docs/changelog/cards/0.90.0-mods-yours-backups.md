# Mods: your own mods in one teal pill, and a backup mod's backups in both apps

**Branch:** t3/hopper-master-session   **Commit:** b5d0a2c6 (released in 0.90.0)   **Size:** M
**Apps:** both. The pill, the wording and the filter/sort exist in desktop and Hopper Server; the split copy-link is in both; backup-mod backups were desktop-only and are now in Hopper Server too, with delete on desktop.

## From -> to
- Before: a mod you added wore a yellow "Added by you" chip, and a group member's change sat beside it as a blue "Added by Mia". The mod page's copy button copied the project ID. Only desktop listed a backup mod's backups, only when its jar was installed, as one flat list with no delete.
- After: one teal pill "＋ Your mod", the group's change in a quiet grey half inside the same pill. The site button and a copy-link half are one split pill. Both apps list a backup mod's backups by world folder, with restore, delete and (in the panel) download.

## Strings
| Case | Before | After |
|---|---|---|
| you added a mod | `Added by you` | `＋ Your mod` |
| a group member changed it too | `Added by you` + `Added by Mia` | one pill: `＋ Your mod │ Added by Mia` |
| only a member changed it | `Turned off by Mia` | plain grey `Turned off by Mia` |
| filter and sort | `Added by you`, `Added by you first` | `Your mods`, `Your mods first` |
| side card | `Added by you` | `Your mod` |
| mod page copy | copies the project ID | copies the page link, tooltip `Copy link` |
| one backup mod backup | — | `1 backup`, not `1 backups` |

## Notes for the maintainer
- Two Claude review passes measured the pill and the split (height 44 vs 32 and a full outline were found and fixed, then re-measured to 0 px).
- The pill's divider is a hairline (~1.1:1) so the pill reads as one object.
- Restoring or deleting a backup-mod backup keeps a copy but writes no History entry (panel backup restore behaves the same); say so if asked.
