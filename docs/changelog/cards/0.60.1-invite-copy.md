# Friends: the invite code is copied, and the join field says what it wants

**Branch:** friends-invite-ux   **Commit:** d5706f8   **Size:** S
**Apps:** desktop only (the Friends page has no Hopper Server web equivalent)

## From -> to
- Before: making an invite printed the code inside a sentence ("Give them this code: …") with no way to click or copy it, and the join field said only "Their 8-character code".
- After: making an invite puts the code on the clipboard automatically and shows it in a tinted chip with a Copy button. The join row says "Have a code from them?", the field says "Paste their invite code", and Join sits beside it. A caption explains the one-use, 15-minute code.
