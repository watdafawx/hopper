# Server mods: a pack's own override jar shows as the pack's mod

**Branch:** t3/ab7a6366   **Commit:** 261c133   **Size:** S
**Apps:** Hopper Server web UI (desktop got it in 93c0929)

## From -> to
- Before: the pack's override jar (CC: Tweaked 1.120.2) had a "Unknown" chip, counted under Unknown, and its peek said "unknown source" and "Hopper doesn't know where this jar is from". The right-click menu offered "Follow a source...".
- After: no Unknown chip, not counted as Unknown. The peek and menu offer Open in Browse (CC: Tweaked's page) and Open on CurseForge. No Follow, Update, versions or lock. Where Versions would be: "This jar comes with the modpack, so the pack updates it."
