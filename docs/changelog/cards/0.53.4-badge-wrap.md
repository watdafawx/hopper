# Count badges never wrap or clip, at any number

**Branch:** claude/badge-wrap-ce484d   **Commit:** c5efdba   **Size:** S-M
**Apps:** both (rail badge, shared helpers; web history badge)

## From -> to
- Before: the orange count on the collapsed Updates icon (Mods tab rail) was an absolutely placed box sized to the 16 px icon, so 3+ digits stacked vertically and clipped.
- After: one-line pill at any digit count (1, 99, 175, 1234, 12345), a circle for one digit. The rail button grows on the right so the badge never covers the next icon. Exact number stays in tooltip / aria-label (no `99+` cap in the rail).

## Root cause
Desktop: absolute badge had no `whitespace_nowrap` / `flex_none`; an absolute box shrinks to its containing block (the 16 px icon), so text wrapped. Web had `min-width` but no reserved room, so wide numbers overlapped the next icon.

## Shared helper
- Desktop `widgets::count_badge(text, fill)` (+ `rail_badge_extra`, unit tested).
- Web `.cbadge` in `app.css` (rail `.bdg` shares it); `--bw` on the button reserves room.
- `widgets::chip`, `pill`, `chip_lift`, `underline_tabs` now `whitespace_nowrap`.
