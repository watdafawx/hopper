# Friends: shared settings show the summary card from 3 mods

**Branch:** t3/friends-shared-settings-manage   **Commit:** b52d6a4f   **Size:** S

Context: the summary card and its Manage window were added in 0.85.0 (`0.85.0-friends-shared-settings-manage.md`).
