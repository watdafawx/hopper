# Versions dialog: "Same notes as" only when there are real notes

**Branch:** claude/changelog-same   **Commit:** see `git log claude/changelog-same -1`   **Size:** S
**Apps:** both (desktop dialog + Hopper Server's mod versions card; one shared function in hopper-core)

## From -> to
- Before: v1.6.6 (no notes) said "No changelog for this version." but older empty v1.6.5 said "Same notes as v1.6.6".
- After: every version without notes says "No changelog for this version."; "Same notes as X" only when the text a reader sees is identical and not empty.

Cause: `install::changelogs` turns an empty changelog into a "No changelog" italic block; as markdown that is the same string on every empty version, and the old compare was on raw strings.

## Screenshots
None. The dialog loads live CurseForge/Modrinth data and can't be fed a fake list without a code hack; the logic is covered by unit tests instead. Not run on screen.

## Measurements
No layout change: only which text a card picks. Nothing measured.
