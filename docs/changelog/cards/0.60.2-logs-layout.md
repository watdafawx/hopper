# Logs & crashes: the crash list and the older logs fill the page

**Branch:** logs-layout   **Size:** S
**Apps:** Hopper desktop only (Hopper Server's web UI has no crash split; its logs page is a single column and was already full width)

## From -> to
- Before: the top cards and the Crash Assistant banner stretched the full width, but the crash list/report split stopped at a fixed 56 rem, and the Older logs pane stopped at 48 rem, leaving a large blank strip on the right at window widths over ~1400 px.
- After: both take the width the page gives them, so the report card ends on the same right edge as the top cards and banner at every width, and the Older logs pane (and its empty state) uses the whole page.

- Built the branch and ran a throwaway app on a scratch data dir with one fake crash report.
- On screen: opened Logs & crashes → Crash reports and measured the right edges above; opened Older logs and checked the empty state centres on the page.
- NOT checked: narrow windows (the caps never applied below ~1400 px, so the narrow layout is unchanged); the other Logs & crashes sub-tabs (latest.log/debug.log were already full width).
