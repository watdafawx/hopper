# Versions and changelogs: "Other versions" cards show only their own notes

**Branch:** claude/changelog-other-versions   **Commit:** 20da3b5   **Size:** M
**Apps:** both (desktop + Hopper Server)

## From -> to
- Before: the installed and newer cards were trimmed (0.52.1), but opening a card under "Other versions" (roll back / older files) showed its whole cumulative text, 5.3.3 down to 5.3.0.
- After: an opened Other-versions card shows only its own version's notes, with a collapsed "Earlier versions (N)" row for the rest. N now counts sections (same-level headings), not every line with a version number in it (the "36" seen on the installed card).
