# Hopper Server: nodes and moves hardened (A6)

**Branch:** t3/multi-panel-a6-hardening   **Commits:** b665760, 0cbdda6, fbe1af6   **Size:** L (review + fixes + docs)
**Apps:** Hopper Server only. Nothing in A6 changes desktop (gaps listed below).

## From -> to
- Before: a user or token limited to one server could read or cancel other servers' jobs; lowering a node's level didn't stop a running move; a node could be updated or removed mid-move; the setup code went into the log and journal; the Linux data folder was readable by every user; MCP audit rows said "local".
- After: jobs are scoped per server; every move step reads the node's level again; update is refused (409) during a move and removing a node ends its moves; an older node is refused before a move starts; the setup code is console + setup-code.txt only and all log lines are redacted; the data folder is 0700 on Linux; MCP rows carry the caller's address.
