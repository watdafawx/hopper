# Hopper and Hopper Server write a crash log when they close unexpectedly

**Branch:** t3/bc155732   **Commit:** 005a96c   **Size:** S
**Apps:** both.

## From -> to
- Before: when Hopper hit an internal error it closed with nothing written to disk.
- After: both apps append the error, where it happened and a stack trace to `crash.log` in their data folder (Hopper: next to settings.json; Hopper Server: next to hopperd.log). The file stays under about 1 MB.
