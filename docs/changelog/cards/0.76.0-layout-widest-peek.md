# Pages fit beside the widest side panel (mod rows, header stats, Servers/Browse/friends, server Logs and Worlds bars)

**Branch:** t3/layout-widest-peek-fit   **Commit:** c486bc0   **Size:** M (ran over: ~L)
**Apps:** both (desktop: mod rows, header, side panel caps; Hopper Server: Logs and Worlds toolbars)

## From -> to
- Before: at 960 px with the mod page at its widest, mod names shrank to a few letters while Remove/Update kept their columns; "Update pack to X" could push the header stats off the edge; Servers, Browse and the friends panel let the side panel squeeze the page (Browse results overlapped SORT, the friends banner wrapped one letter per line); the server panel's Logs and Worlds bars wrapped to two lines when narrow.
- After: Remove moves into the row ⋯ menu first, the name keeps ~12 characters, then the Update column goes into the menu ("Update to X"). The header stats fold (fewer figures, then hidden) before anything clips. Every docked panel is capped so the page keeps `PAGE_MIN` (30 rem). Browse hides its filters while a mod page is open at narrow widths. Logs and Worlds bars stay on one line: labels shorten, buttons go icon only, then a ⋯ menu.
