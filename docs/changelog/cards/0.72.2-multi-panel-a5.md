# Move or copy a server between the main panel and its nodes

**Branch:** t3/multi-panel-a5-move-copy-server   **Commit:** 91fe049   **Size:** L
**Apps:** Hopper Server (API + web UI). Desktop: History shows moves (no Undo); the Move or copy action on desktop is not built (stopped before going past L).

## From -> to
- Before: a server could only live where it was made; moving it to a node meant copying folders by hand.
- After: "Move or copy to…" (server page "…" menu, server row menu) opens one dialog with where to, Move | Copy, Bring backups and the checks; progress shows in the same box; a broken link waits, then pauses with Resume, sending only what's missing; a failure leaves nothing on the target; the moved copy stays stopped with a banner (Keep using this copy / Delete the old copy… with a tick box).

## Second review (A5), 2026-11-14
A separate review found gaps in the move. The main one a player sees: a moved copy could still start by itself. All fixed.

What changed on screen:
- Start is disabled for a moved copy (or one being sent) everywhere: server page, list "…" menu, Overview card. Tooltip: "This copy was moved to vm. Choose Keep using this copy to start it here." The command palette leaves Start out; a bulk start skips it with that reason.
- Keep / Delete on the banner show only to owner-level people; the banner shows to everyone.
- History reads "Test Server moved" (was "moved 1 file").
