# New instances get memory that fits the pack and the PC

**Branch:** t3/smart-default-instance-memory   **Commit:** 64766a85 (+ merge of main 0.77.2: 157bd03d)   **Size:** M
**Apps:** both (desktop instances + desktop host dialog; Hopper Server's New server dialog uses the same rule)

## From -> to
- Before: every new instance got a flat 8 GB from Settings (Modrinth, custom, share codes), and CurseForge packs got the author's number as-is, even 12 GB on an 8 GB PC.
- After: new instances take the pack's recommended memory, else an estimate from the mod count, fitted to this PC so Windows keeps max(4 GB, 30%). Settings shows "Auto (X GB)" plus a line saying why; the first Play says it once when the PC couldn't give what the pack asks.

## The rule (`crates/hopper-core/src/memory.rs`)
- Wanted: pack's `recommendedRam` (>= 2 GB, rounded to whole GB), else by mod count: 0-49 -> 4 GB, 50-149 -> 6, 150-299 -> 8, 300-599 -> 10, 600+ -> 12. Fabric/Quilt one tier lower (lighter loaders).
- Fit: PC RAM rounded to whole GB; client keeps max(4 GB, 30%) free, server keeps max(2 GB, 20%). Cap floored to whole GB, min 2 GB. Unknown RAM = no cap.
- Client cap on 4/8/16/32/64 GB PCs: 2/4/11/22/44 GB. Server: 2/6/12/25/51 GB.
- Picked at each launch while the instance is on Auto (memory 0 + `memory_auto`), so it follows mods added later and pack updates (`apply_pack` records the pack's number).
- Hand-set memory always wins. Old instances (no `memory_auto`, memory 0) keep the Settings default (8 GB): they ran fine, and on an 8 GB PC they'd drop to 4 GB under a working pack.
- Research (real manifests, read-only): ATM10 498 mods asks 8196; BMC5 382 asks 10720; DeceasedCraft 317 asks 6144; TNP Limitless 8 946 asks 12288; Craft to Exile 2 (401) and Star Technology (188) ask nothing. Modrinth's `modrinth.index.json` has no memory field, so Modrinth packs use the mod-count estimate.

## Notes for the maintainer
- CF/Prism/Modrinth-folder instances keep that launcher's memory (unchanged).
- Server side has no mod count, so servers without a pack number use the old modded/vanilla default, fitted to the host.
- Instances made before this change stay on "Default (8 GB)". To move them to Auto later, set `memory_auto` on instances with memory 0 (one-line migration); left out on purpose.
