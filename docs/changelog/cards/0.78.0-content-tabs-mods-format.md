# Packs, shaders and data packs look like the Mods tab

**Branch:** t3/content-tabs-mods-format   **Commit:** 3b87ef4e (work in 7bbbfbb4 + a947a4bf, main merged)   **Size:** M
**Apps:** both (desktop: Resource packs, Shaders, Data packs; web: Data packs and Mods empty state. The web UI has no Resource packs or Shaders tab.)
**Design:** option A, https://claude.ai/artifact/LV1swMRw9tc3rmERv6zHrg (audit items #16-18)

## From -> to
- Before: pack rows had their own order column (grip + rank circle), so names sat 97 px right of where Mods puts them, and empty tabs showed bare group headings ("In worlds 0", "Off 0") or nothing.
- After: every content tab uses the Mods toolbar, columns and row height. Names line up with Mods. In game / Always on / In worlds / Off are quiet section headings. The rank is a "1st/2nd/3rd" chip by the name. The drag grip only shows on the hovered row, and the row menu has Move up / Move down. Empty tabs show one shared empty state, 64 pt under the tabs, worded per tab, with one Add button ("No world yet" + Find Paxi when data packs have nowhere to go).

## Files
- `src/gpui/addons.rs`: pack rows use Mods columns, short pill, empty states
- `src/gpui/pack_where.rs`: rank chip, hover grip, Move up/down menu
- `src/gpui/datapacks.rs`: "No world yet" empty state
- `src/gpui/widgets.rs`: `empty_top` / `EMPTY_TOP`; tags keep width
- `crates/hopperd/ui/src/DataPacks.svelte`: same layout in the web UI
- `crates/hopperd/ui/src/Mods.svelte`, `app.css`: shared empty state

## Notes for the maintainer
- Desktop group headings stay at row height (uniform_list needs one height); the mock had 40 px. The web has 40 px.
- Web "Find Paxi" opens Browse mods without typing "Paxi" into the search.
- `widgets::mod_tags` change (tags keep their width once fitted to `room`) also applies to the Mods tab, the only other caller with `room`.
