# Hopper Server: another panel's files work from your page, and help to trust its certificate

**Branch:** t3/multi-panel-b4-cross-origin-files   **Commit:** 8db85cf   **Size:** M
**Apps:** Hopper Server only (multi-panel is web UI only; desktop has no added panels)

## From -> to
- Before: on a server from another panel, downloads, thumbnails, previews, backups, zip entries and mod drops either failed or hit this panel's own address; a certificate problem only said "open its page".
- After: they all go to that panel (one-use links for downloads and new tabs, token reads for pictures and text, uploads to its API), and Add a Hopper Server can download the panel's certificate with install steps.
