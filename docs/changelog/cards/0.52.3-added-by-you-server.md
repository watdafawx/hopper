# Server Mods tab: pack mods no longer all show "Added by you"

**Branch:** claude/added-by-you-bug-d26907   **Commit:** 304bd39   **Size:** S
**Apps:** desktop (server Mods tab, local + Hopper Server pairing) and Hopper Server (same data, web list hardened)

## From -> to
- Before: server TNP-LL8 (set up from a server pack, no `from_pack` marks) showed ~1013 of 1158 mods as "Added by you" in the desktop.
- After: marks come from the one rule `PackMods` (the pack manifest's mod list). If the pack's list can't be had, none show as yours.

## Root cause
Commit 306ceea (2026-11-06, "Servers: Mods tab is the instance Mods table") put server mods in the instance table. That table reads `Addon.from_pack` directly (addons.rs filter, chip count, row tag). Servers made from a server pack have no marks, which is why d5203cc (2026-11-01) added `PackMods` for the old server list, MOTD and updates. The new path (`GET /servers/{id}/mods/instance` and the local `server_mods::load`) bypassed `PackMods`, so every mod counted as yours. Also, web list `pack_mod` fell back to raw `from_pack` (all false) when the list was unavailable (no CF key on the panel, pack file not cached).
Instance side untouched (249 stays).
