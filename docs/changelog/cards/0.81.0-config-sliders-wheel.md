# Config sliders follow the pointer; the mouse wheel turns number fields

**Branch:** t3/ce2c1f47   **Commit:** 7ccf9e44   **Size:** M
**Apps:** both (desktop Configs tab + other number fields; Hopper Server web config editor + every number field)

## From -> to
- Before (desktop): dragging a config slider didn't track: the thumb and the number stayed on the old value mid-drag and any redraw snapped the thumb back to the file's value; float steps were uneven; the wheel did nothing on numbers.
- After (desktop): thumb and number follow the pointer, the value is kept on release, ends are clamped; float sliders step tidily; the wheel over a number steps it (Shift x10, min/max respected, page doesn't scroll); the - / + buttons use the same math.
- Before (web): wheel did nothing on config numbers; float step was a fixed 0.1/0.01.
- After (web): same step rules as desktop (`stepper.js` mirrors `configedit::stepper`), wheel steps config numbers and every `<input type=number>`. The native range slider (click-to-jump, drag, past the ends) already behaved: no change there beyond the shared step.
