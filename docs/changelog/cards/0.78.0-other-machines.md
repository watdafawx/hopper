# Hopper Server: nodes and signed-in panels are one "Other machines" list

**Branch:** t3/unify-other-machines   **Commit:** a4942cb3   **Size:** M-L
**Apps:** Hopper Server only. Desktop has no such page (it pairs a panel and shows that panel's nodes); differences listed below.

**Mock:** https://claude.ai/artifact/HDJeh67KsLdHhQjQoYspnc. Picked option A, a page in Settings › Other machines. It keeps one list in the place where Nodes already was, leaves room for long names plus a reason on each row, and adds nothing to the top bar. B, the list in the sidebar, fails on a phone: 11 machines push the servers off screen. C, a top tab, puts a tab most players never use in the top bar and splits the job over two places.

## From -> to
- Before: there were two lists in two places. Settings › Nodes showed nodes, and the server-list footer had "Several panels in one page" for signed-in panels. Each had its own add flow, its own wording and its own chips.
- After: Settings › Other machines is one list. Each row has a light, the name, a status line, a chip for how it's connected (Node / Signed in), a server count, one action button and a ⋯ menu. Rows that need attention sort first. A single "Add a machine" button suggests a node first; "Sign in to a panel instead" covers a friend's panel. The sidebar and Overview group servers by machine the same way for both kinds. Old `#/settings/nodes` links now open Other machines.

## Notes for the maintainer
- Desktop differences (desktop not changed):
  - desktop captions a paired panel "Hopper Server · N" and a node "node · via <panel> · N"; the web UI now uses "This panel" / "Node" / "Signed in" chips with "N servers · hopperd V"
  - desktop pairs as a device, so it has no "Signed in" kind
  - desktop has no Add a machine flow: nodes are added on the panel
  
  A follow-up could make desktop's group headers use the same chip words.
- Security, auth, roles, the setup code, TLS and the cross-origin checks are unchanged. There are no new API routes; the UI only calls existing ones (`/nodes`, `/nodes/keys`, `/nodes/{id}`, `/auth/me/panels`).
- Access.svelte and config.rs were not touched (another session owns them).
- In the 248 px sidebar, the "Signed in" chip plus ⋯ leave a panel name only about 8 characters ("sam's-box…"). The full name is in the tooltip and on Other machines.
- After the main panel restarts, an offline node shows "0 servers": the panel no longer knows that node's servers, so its count is lost. This was the same before.
- App-wide, `--red` small text is about 4.4:1 on cards in both themes. Only the Other machines rows were fixed here; changing the token would affect every page.
