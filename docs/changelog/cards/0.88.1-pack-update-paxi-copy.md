# Packs: Update changes each copy of a pack in its own folder (Paxi too)

**Branch:** t3/fix-pack-update-paxi-copy   **Commit:** e6ffb25b   **Size:** M
**Apps:** desktop only. Hopper Server's data packs view has no update flow (list / where / order only), so there is nothing to match.

## From -> to
- Before: a pack in both `resourcepacks` and `config\paxi\resourcepacks` had one offer per project. Update changed only the instance copy, both rows said "Updated", and afterwards both rows offered the same update again ("Update all (2)").
- After: offers are per file. Update on a row changes that row's file in its own folder. Update all updates every copy in place. "Updated" shows only on a row whose file changed. The task names the folder and old file for a non-instance copy ("Updating Fresh Waystones Texture in Paxi (fresh_waystones_copy.zip)"). The review groups copies: "Fresh Waystones Texture (2 copies)", "Update 2".
