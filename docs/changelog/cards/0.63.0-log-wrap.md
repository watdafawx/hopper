# Long log and console lines wrap instead of being cut off

**Branch:** t3/log-wrap-long-lines   **Commit:** 307857f   **Size:** M
**Apps:** both (desktop: console + instance logs + server logs share one view; Hopper Server: Logs & crashes viewer. Its Console already wrapped.)

## From -> to
- Before: desktop log/console lines cut off at the right edge, no scroll. Web log viewer needed sideways scrolling (600-char line ran to x=4540).
- After: both wrap to the view width, continuation rows indented to the text column, number on the first row.
