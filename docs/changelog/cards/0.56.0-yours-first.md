## Notes for the maintainer
- Persistence like "Updates first": desktop keeps it in memory per Mods view (default off, "Updates first" default on; neither is saved); web saves `hopperd-mods-yours-first` in localStorage like `updates-first`. Same behavior as before for the old toggle, so left alone.
- Desktop: Resource packs / Shaders / Data packs use the same `sort_button`, so they get the row too (only the Mods tab was checked on screen). Web: only `Mods.svelte` has this sort menu (the server's Data packs page has none), so nothing else to change there.
- Sort button label with both on reads "Updates, yours first, then <col>".
- Desktop `has_pack` is `inst.pack.is_some()`; a pack with no own mods still shows the row (it just has no effect).
