# Clear message while a NeoForge server starts

**Branch:** (merged before this changelog existed)   **Size:** S
**Apps:** Hopper Server (the shared library change is in `hopper-core`)

## From -> to
- Before: a NeoForge client joining a sleeping server saw "server is not running NeoForge".
- After: it sees "<server> is starting: 1%, starting java. Join again in a moment." The player still has to rejoin once the server is up. The router now keeps NeoForge mod data in its saved server answer, and a server with no saved answer counts as modded.
