# Group packs: everyone's changes reach everyone, and the mod says who

**Branch:** t3/fix-follow-auto-apply   **Commit:** f3de207   **Size:** L
**Apps:** desktop only (Hopper Server has no Friends or groups)
**Relay:** unchanged (client-only design, uses the existing `recipes` event with `key = "~copy"`)
**Mock:** https://claude.ai/artifact/H7aECQhyB6xp2DnyD14M3A (picked B: a chip on the tag line, where "Added by you" sits)

## From -> to
- Before: in a group, only the pack's owner sent changes. A member turning a mod off, adding, removing or updating one changed only their own copy.
- After: with "Keep my packs the same as the group" on, any member's change to a group pack reaches every member in about 0.2-2.4 s. If two members change the same mod at once, the later change wins on every PC. The mod's row shows who changed it last ("Turned off by Mia", "Added by Mia", "Updated by Mia", "Removed" leaves no row). Your own changes show no chip.
- Group panel text now says changes go both ways.
