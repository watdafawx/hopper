Hopper 0.53.0 · Hopper Server 0.48.0

7 Nov 2026

Mods tab: the filters are a row of icons

Apps
Both: Hopper and Hopper Server.
Before
A wide row of text tabs with counts (All, Updates, Disabled, Archived, Client-only, Unknown), plus separate "Added by you" and "Config changed" chips, "Update all" and a separate check button, and a "Sort: ..." text button.
After
One row of icons. The picked filter opens to its name and count and "All" starts open; the others show a tooltip. "Added by you" and "Config changed" are in the row, tinted with a ring when on, and combine with any other filter. "Client-only" shows on server pages only. Update all and "Check for updates" are one split button (the check side says when it last ran), and Sort is an icon that shows its name only when it is not the default order. On narrow windows the search stays on the first row.
  • src/gpui/widgets.rs
  • src/gpui/addons.rs
  • crates/hopper-core/src/update_list.rs
  • crates/hopperd/ui/src/Mods.svelte
  • crates/hopperd/ui/src/SortMenu.svelte
  • crates/hopperd/ui/src/app.css
partly checked
  • Tests: the "checked N min ago" wording; all of Hopper's tests pass.
  • Seen on screen in both apps on throwaway instances and servers with seeded data: default, Updates, Updates plus Added by you, Config changed, Disabled, Archived, Unknown, Client-only, the split button with its checking spinner, tooltips, keyboard focus ring, and the narrow layout.
  • Not checked: Archived and Unknown on the desktop, the check button's real "checked N min ago" text on a finished check, arrow keys on the desktop, resource-pack tabs, and a real instance or server with thousands of mods. There is no old-build screenshot for the web side (the before shots are the desktop ones).

Hopper 0.52.3 · Hopper Server 0.47.3

6 Nov 2026

Servers: the Mods tab no longer marks nearly every mod "Added by you"

Apps
Both: Hopper and Hopper Server (one shared rule).
Before
A server made from a server pack showed about 1,000 of its 1,158 mods as "Added by you". The server list ignored the pack's own mod list; instances were right (249).
After
A server compares against the pack's mod list like an instance does. If that list isn't available, nothing is marked as yours, instead of everything.
  • crates/hopper-core/src/modpack.rs
  • crates/hopperd/src/mods_api.rs
  • crates/hopperd/src/parity_mods.rs
  • src/gpui/store/server_mods.rs
partly checked
  • Tests: 4 new for the pack marking, and all of Hopper Server's tests pass.
  • Seen on screen on a test server (12 mods, pack lists 9): desktop and the web UI in a real browser, with the pack list and without it. The instance code path is untouched.
  • Not checked: the real TNP-LL8 server. It most likely hit "pack list not available" on the panel; that is unconfirmed. After updating, its count should drop from about 1,013.
  • Not checked: a before screenshot of the web UI (no old build to hand).

Crash cards: a timing problem inside a library no longer blames the mod the loader names

Apps
Both: the desktop crash card and Hopper Server's crash card.
Before
A TNP-LL8 crash caused by a loading race inside Moonlight Lib showed Supplementaries as "Certain" with "Turn off Supplementaries". The same race had blamed Snowy Spirit the day before.
After
Moonlight Lib is "Likely": "start again, this is a timing problem inside Moonlight Lib and often goes away; if it keeps happening, update it". Supplementaries is "Possible", and there is no Turn off button.
  • crates/hopper-core/src/crashdetect.rs
  • crates/hopper-core/src/crashengine.rs
  • crates/hopperd/ui/src/ServerCrash.svelte
  • crates/hopper-core/tests/crash_corpus/
  • design/crash-detection.md
partly checked
  • Tests: the new rule has fixtures from both real crashes (5 and 6 Nov) and a case where the error is inside the named mod's own code, which still blames that mod. The whole crash corpus passes and no older case changed its verdict.
  • Seen on screen on a test server in both apps.
  • Not checked: a real game-instance crash card, narrow layouts, and the "Why?" list. There is no web "before" shot.
  • Only crashes where the loader's mod has the error thrown from another mod's code are covered.

Versions and changelogs: "Other versions" cards trimmed too

Apps
Both.
Before

Hopper Server.
