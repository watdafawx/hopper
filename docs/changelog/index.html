Hopper Server: pick servers across panels and start, stop, restart or command them together

Apps
Hopper Server only. The desktop's server list has no selection or bulk actions yet, so the two are not in step.
Before
Each server had to be started, stopped or restarted on its own page, and the list had no filters.
After
A Select button in the list header turns on tick boxes. Pick servers in every panel's group (click, drag across, or Ctrl+A), then use Start, Stop, Restart or Command in the selection bar. Servers where you can only look are skipped and never sent anything, and each panel checks your role and keeps its own audit log. The list can be filtered by panel and by state (All, Running, Stopped, Crashed).

Hopper desktop (the shared library change also reaches Hopper Server).
Before
