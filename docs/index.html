Why Hopper

Built out of frustration, grown out of need

Hopper started as a tool just for me. The CurseForge app was painfully slow, and everyday things took far too many clicks. Want to know what a mod update changes? Open the mod's page, go to Files, find the newest version, click its changelog icon, then repeat for the next mod. Added a few mods of your own to a pack? It won't update until you turn off "Allow content management". And nothing kept my server's mods in line with the pack.

So I wrote my own. In Hopper, every changelog since your version is one click from the mod list, and packs update with your own mods kept. Every feature since has come from something I needed while playing and running servers: performance tracking when a pack felt sluggish, Server sync when keeping the server up to date became a chore. If you've hit the same walls, it should feel right at home.

Full disclosure: I have a full-time job, and Hopper is what I do after it. To keep up, a lot of the code (especially the boilerplate) is written by AI. The testing isn't. Every feature gets clicked through by hand, by me, in the real app, usually with a modpack open in the background. Claude does the typing; I do the poking.

— watdafawx, Hopper's developer

Features

Everything a modded player needs

Hopper replaces the CurseForge app for playing packs, then goes further: performance tracking, a proper log viewer and real server tools.

Library

Every instance with its pack art, playtime, mods, worlds and screenshots. Update packs with a preview that keeps your config changes.

Browse

Search CurseForge and Modrinth for mods, modpacks, shaders, resource packs and worlds. Dependencies come along.

Performance

Each run is recorded: FPS, 1% lows, frame times, CPU, RAM, GPU, GC pauses and load time. Compare Java presets side by side. Nothing is injected.

Logs & crashes

The game's live log, debug.log and every crash report, with search and an errors-only filter. One click shares a log on mclo.gs.

Servers

Start, stop and watch servers through Crafty, MCSS or Pterodactyl, or host one on this PC with Java picked for you.

Server sync

Compare a server with its pack and push or pull mods and configs. Client-only mods stay off. Backups and undo included.

Other launchers

Manage Modrinth App, Prism / MultiMC, ATLauncher, GDLauncher and FTB App instances where they already are.

Accounts

Several Microsoft accounts. Try skins on a 3D model that walks, runs, swims and dances, then change your skin, cape and name.

Peers

Sync an instance with a friend's PC on your network, so everyone joins with the same mods.

Mods

Hundreds of updates, one click

See every mod with its file, author, side and the version it moves to, and read what changed before you update.

  • Updates shown old → new, with "Update all"
  • Every changelog since your version in one window, with "Update to this" or "Install this version"
  • "Added by me" shows the mods you added to the pack, and pack updates keep them
  • Profiles to switch sets of mods on and off
  • Files CurseForge only lets you get in a browser are picked up from Downloads automatically
Servers

Your servers, next to your packs

Hopper works with servers wherever their files are: this PC, another PC at home, or a host running Pterodactyl.

  • CPU, memory, players and world size, live
  • Console, backups, server.properties and JVM presets
  • Daily restarts with warnings, and crash recovery
  • Host a pack's server on this PC in a few clicks
Server sync

Server and pack, always in step

Update the pack, then update the server to match. Hopper knows which mods belong on a server and which don't.

  • Mod by mod: in sync, update, client only, server only
  • Configs compared too
  • Every change backed up, with history and undo
Logs & crashes

Every log, one tab away

The game's live log, debug.log and every crash report in one place, quick to search even when they're huge.

  • Search, and "errors and warnings only"
  • The latest crash's summary up top
  • Share a log on mclo.gs with your name taken out
  • Crash help: checks the pack for Crash Assistant, KostromDan's mod that explains crashes in game, and installs it in one click
Server panels

Works with the panel you already use

Hopper talks to Crafty Controller 4, MCSS and Pterodactyl (or Pelican) through their own APIs with an API key you make in the panel. Your panel keeps running the servers. Hopper is the remote control.

  • One panel at a time. Settings → Servers takes one panel address and key.
  • Crafty needs an API key with the Commands permission. Its self-signed certificate is accepted when you tick the box.
  • MCSS doesn't report ports, so servers pair by folder or name.
  • Pterodactyl needs a client key (ptlc_…). Its console is a websocket Hopper doesn't read yet.
  • Server sync needs the files as a folder: this PC, or a share on another PC at home. No SFTP or FTP yet.
  • Hosted by Hopper servers run while Hopper does. Quitting stops them, saving the world first.
Open source

Easy to hack on. Fork it, change it, send a PR.

Hopper is plain Rust with no web stack, MIT licensed, and built to be changed. If it's missing something you need, it's likely a small change.

Build it in one command

Install Rust, clone, run. Dependencies are optimized even in dev builds, so the app runs at full speed while you work on it.

git clone https://github.com/watdafawx/hopper
cd hopper
cargo run --bin hopper

Small, separate pieces

The library (src/*.rs: CurseForge, Modrinth, instances, servers, logs) is apart from the app (src/gpui/), with tests for the library. A new server panel is one file implementing the ServerPanel trait.

Themes are files

Drop a theme JSON in the themes folder (Settings → Appearance opens it) and press refresh. No rebuild needed.

Scriptable

hopper --mcp serves MCP on localhost, so scripts and AI agents can screenshot, click and navigate the app. Handy for testing your changes.

Forks and pull requests are welcome. Fix a bug, add a panel or a launcher, or take it somewhere new. Fork on GitHub · Open a PR · Report an issue

Get started

Up and running in a minute

Download

Get hopper.exe and run it. Settings → Updates & install → Install adds Start menu and desktop shortcuts, no admin needed.

Point it at your packs

The setup wizard finds CurseForge's Instances folder and other launchers on this PC. Nothing is copied or moved.

Add a CurseForge key

Free from console.curseforge.com. Modrinth works without one.

Why a key of your own? CurseForge requires every app to use an API key for searching, installing and checking for updates. Hopper doesn't ship a shared one, so each person uses their own. It stays on your PC in Windows Credential Manager.
FAQ

Questions

Is Hopper free?

Yes. It's open source under the MIT license, with no ads and no accounts of its own.

Will it touch my existing CurseForge instances?

Hopper reads CurseForge's folder in place and works on those instances directly, the same way CurseForge does. Updates and syncs make backups first, and pack updates show a preview before anything changes.

Does it work on macOS or Linux?

Not yet. Hopper is Windows only for now (Windows 10 and 11).

How does it measure FPS without a mod?

It reads Windows' own present events for the game's window, plus Java's GC log. Nothing is injected into Minecraft. FPS needs admin or membership in the Performance Log Users group.

Can it manage a server at a host?

If the host runs Pterodactyl (or Pelican), add it as the server panel for start, stop, restart, kill, stats and console commands. Copying files to a host isn't supported yet; use your host's file manager or SFTP with the server pack Hopper downloads.

Was AI used to build Hopper?

Yes, and proudly so. Hopper is a hobby project squeezed in around a full-time job, so a lot of the code (especially the boilerplate) is written by Anthropic's Claude. The testing is all by hand: every feature gets clicked through in the real app before it ships. Claude does the typing; the developer does the poking. From v0.8.0 on, commits Claude helped with say "Co-Authored-By: Claude", so the commit history shows exactly which ones (earlier history was folded into one fresh start).

How do updates work?

Hopper checks its latest GitHub release when it starts and offers to update itself. Each release lists what changed in the What's new dialog.
