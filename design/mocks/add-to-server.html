C. Setting: add new mods to the server too

Automatic, like "Update servers with the pack".

Add mods I add to the paired server too
Running servers load them after their next restart.
  • Off by default (no surprises on a shared server), so the default stays silent: the problem stays for most players.
  • Changes a server's files without asking.

Why A: it reaches every add path from one place, asks once with the facts (which mods, which server), never changes a server unasked, and can't be missed: it stays until clicked or closed. A running server still gets the jars (harmless until restart) and the server page shows the existing "Synced while running: restart the server" line.
